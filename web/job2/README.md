# 纸灯书店

纸灯书店是一个面向读者和管理员的书店 Web 系统。它把图书浏览、书袋购物、订单管理、个人书架、评论互动和书友社区放在同一个系统中，并使用 MySQL 保存真实业务数据。

项目包含两个端：

- 读者端：逛书架、查看书籍详情、收藏、书袋、订单、个人中心、论坛、二手书市、读书会活动、阅读成长。
- 管理员端：运营总览、图书 CRUD、用户管理、订单管理、社区管理、库存管理和经营分析。

## 功能介绍

### 读者端

#### 逛书架

- 书籍推荐轮播，支持上一条、下一条和直接选择推荐项。
- 按文学小说、生活方式、设计与艺术、社会观察等分类浏览。
- 按书名或作者搜索。
- 支持推荐、评分最高、价格最低和价格最高排序。
- 支持全部、高分推荐、折扣专区、库存紧张和我的收藏快捷筛选。
- 点击书籍卡片可以打开完整详情。

#### 书籍详情

- 展示书名、作者、评分、价格、库存和简介。
- 展示 ISBN、出版社、出版时间、作者简介、目录和内容试读。
- 展示相似书籍、评分分布和评论列表。
- 评论支持按最新、有用和评分排序。
- 已购买用户可以提交评分和评论，评论支持点赞、回复和回复点赞。
- 进入详情时会记录阅读历史。

#### 书袋和订单

- 将图书加入书袋，调整数量或移除商品。
- 结算时自动读取个人中心的默认收货地址。
- 支持新建收货地址、切换默认地址和删除地址。
- 下单时写入订单、订单明细并扣减库存。
- 管理员可以更新订单状态。

#### 我的纸灯

- 修改昵称、个人简介和头像信息。
- 管理收货地址。
- 查看收藏夹和订单。
- 管理想读、在读、已读书架。
- 更新阅读进度和阅读分钟数。
- 查看最近浏览、读完数量、阅读分钟和年度阅读统计。

#### 书友论坛

- 推荐、最新、热榜和关注四种信息流。
- 发布标题、正文、标签和图片。
- 查看帖子详情、发表评论、点赞评论和关注作者。
- 支持举报内容和管理员置顶帖子。

#### 二手书市

- 发布闲置书，填写书名、作者、成色、价格和说明。
- 通过地址或文件上传添加封面图片。
- 浏览在售二手书，购买后商品会被锁定。

#### 读书会活动

- 创建读书会，填写标题、共读书籍、时间、地点、人数和活动介绍。
- 上传活动封面。
- 查看活动成员数量并报名或取消报名。

#### 阅读成长

- 加入管理员发布的阅读挑战。
- 更新完成书籍数量和阅读分钟数。
- 查看年度读完榜、阅读时长榜和最近活跃榜。
- 榜单进入页面立即同步，每 10 秒刷新一次，浏览器重新聚焦或点击刷新按钮时也会同步。

### 管理员端

- **运营总览**：查看书籍、用户、订单、帖子和销售额统计。
- **图书管理**：新增、编辑和删除图书，维护价格、分类、库存、封面、ISBN、出版社、目录和试读内容。
- **用户管理**：查看注册用户、角色和资料。
- **订单管理**：查看订单详情，更新待发货、配送中、已送达或已取消等状态。
- **社区管理**：查看帖子、评论、举报和置顶状态。
- **库存管理**：调整库存、暂停销售或标记售罄，保存调整原因并记录库存日志。
- **经营分析**：查看近六个月销售额、热销图书、浏览趋势、二手书和读书会数据。

## 环境要求

- Windows、macOS 或 Linux。
- Node.js 18 或更高版本。
- npm。
- MySQL 8 或兼容版本。
- MySQL 服务运行在 `localhost:3306`。
- MySQL 用户名为 `root`，密码为 `1234`，数据库名为 `bookstore`。

## 数据库初始化

先确认 MySQL 服务已启动，然后在项目根目录执行：

```bash
mysql -uroot -p1234 < schema.sql
```

如果命令行提示数据库不存在，先执行：

```sql
CREATE DATABASE bookstore DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

然后再次执行 `schema.sql`。项目启动时会继续检查并创建阅读书架、论坛互动、库存日志、二手书、读书会和阅读挑战等扩展表。

## 配置数据库

项目根目录可以创建 `.env` 文件，内容如下：

```env
PORT=3001
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=1234
DB_NAME=bookstore
```

如果不创建 `.env`，后端会使用同样的默认值。

## 安装和启动

在项目根目录执行：

```bash
npm install
npm run dev
```

`npm run dev` 会同时启动：

- Node.js API：`http://localhost:3001`
- Vite 前端：`http://localhost:5174`

打开浏览器访问：

```text
http://localhost:5174
```

也可以分别启动：

```bash
npm run server
npm run build
npm run preview
```

其中 `npm run build` 用于检查生产构建，`npm run preview` 用于预览构建后的前端文件。

## 读者操作说明

1. 打开登录页，输入读者账号。
2. 在“逛书架”中选择分类，或通过搜索框输入书名和作者。
3. 点击书籍封面查看 ISBN、作者介绍、目录、试读和评论。
4. 点击心形按钮收藏，点击加号将书籍放入书袋。
5. 打开书袋调整数量，点击结算。
6. 在结算弹窗选择个人中心保存的收货地址，确认后提交订单。
7. 进入“我的纸灯”维护地址、收藏和阅读书架。
8. 在“书友论坛”发布讨论、发表评论、点赞或关注作者。
9. 在“二手书市”发布闲置书，或锁定其他书友的在售图书。
10. 在“读书会活动”创建活动或报名参加已有活动。
11. 在“阅读成长”加入挑战，保存阅读进度并查看实时榜单。

## 管理员操作说明

1. 使用管理员账号登录，系统会自动进入管理端。
2. 在“运营总览”查看当前数据库中的统计数据。
3. 在“图书管理”点击“新增图书”，填写书名、作者、分类、价格、库存和详情信息。
4. 点击图书行的编辑操作可以修改信息，删除操作会移除图书记录。
5. 在“用户管理”查看读者账号和角色信息。
6. 在“订单管理”查看订单商品、地址和金额，修改配送状态。
7. 在“社区管理”处理帖子、评论和举报，必要时置顶内容。
8. 在“库存管理”修改库存和销售状态，填写调整原因后点击保存。
9. 在“经营分析”查看销售额、热销图书和阅读活跃度。

## 数据真实性说明

系统的书籍、用户、订单、评论、论坛、库存和阅读榜单均通过后端接口读取 MySQL `bookstore` 数据库。数据库不可用时，登录和业务接口会返回数据库不可用提示；前端的书籍静态数据只用于页面初始占位，不应被当作数据库业务数据。

阅读榜单由 `reading_shelves` 和 `reading_history` 聚合计算。进入页面后会立即读取数据库，之后每 10 秒同步一次，避免长时间停留时看到旧的榜单数据。

## 常见问题

### 页面提示数据库不可用

1. 检查 MySQL 服务是否启动。
2. 检查 `localhost:3306` 是否可以连接。
3. 检查 `.env` 中的账号、密码和数据库名。
4. 重新执行 `mysql -uroot -p1234 < schema.sql`。
5. 重启 `npm run dev`。

### 端口被占用

后端可以临时更换端口：

```powershell
$env:PORT="3002"
npm run server
```

前端端口可以在 `vite.config.js` 中修改，同时把 proxy 目标指向正确的后端端口。

### 图片无法提交

图片字段只接受图片类型，前端上传大小限制为 3MB，后端请求体限制为 5MB。请压缩图片后重新上传。

### 不同账号登录互相覆盖

请确认使用的是当前版本。当前版本使用 `sessionStorage` 保存 token，可以让同一浏览器的不同标签页分别登录不同角色。

## 开发建议

新增功能时建议按以下顺序：先设计数据库表和关系，再在 `server` 对应模块添加业务函数和路由，最后在 `src` 中增加视图、状态和样式。所有新增接口都应测试未登录、普通读者、管理员、空数据和异常输入场景，并在提交前执行：

```bash
npm run build
```
